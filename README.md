## 📌 Descrição do Projeto

O objetivo deste projeto é realizar uma análise exploratória, tratamento e modelagem preditiva em uma base de dados de vinhos. Utilizando técnicas de Data Science e Machine Learning (como Random Forest), o projeto busca identificar padrões de qualidadee e gerar visualizações claras para apoiar tomadas de decisão.
